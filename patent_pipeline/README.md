# Patent Evidence Pipeline

This folder contains the patent-related data and scripts used to expand and enrich the filovirus knowledge graph.

## Summary

The patent dataset was expanded from **72 patents to 172 unique patents**.

The current patent work includes:

- **172 patent → inventor links**
- **11 patent → existing team paper edges**
- **156 patent → external literature edges**
- **326 candidate patent → virus/protein entity links**

The patent-to-entity links were generated by matching knowledge graph keywords against patent titles and abstracts. These should be treated as candidate `related` links rather than automatically verified claims.

## Main Output Files

All final processed outputs are in `data/processed/`.

### `patent_evidence_expanded.csv`
Master patent dataset containing **172 unique patents**.

### `patent_inventors_expanded.csv`
Patent-to-inventor links for the expanded patent dataset.

### `master_patent_team_paper_edges.csv`
Patent-to-paper citation edges where the cited paper already exists in the team's paper dataset.

Current count: **11 edges**.

### `master_patent_external_literature_edges.csv`
Patent-to-literature citation edges where the cited literature is not currently part of the team's paper dataset.

These external citations are retained as independent literature nodes rather than discarded.

Current count: **156 edges**.

### `patent_entity_links_title_abstract_summary.csv`
Candidate patent-to-KG entity links generated by exact keyword matching against patent titles and abstracts.

Current count: **326 unique human-readable links across 108 patents**.

### `patent_entity_links_review.csv`
Review version of the patent-to-entity links.

The automated review currently classifies:
- **206 links as likely valid**
- **120 links as needing review**

Generic protein terms and abstract-only protein matches are more likely to require manual validation.

## Reference Files

### `kg_keywords.csv`
Knowledge graph keyword and synonym file used for entity matching.

Only rows with `scope = include` were used for the default patent entity matching.

### `filovirus_papers.csv`
Existing team paper dataset used to identify whether literature cited by patents already exists in the knowledge graph paper collection.

## Scripts

### `expand_patent_dataset.py`
Combines the original and expanded USPTO patent search results and removes duplicate patents.

### `build_expanded_patent_evidence.py`
Builds the expanded master patent evidence dataset while preserving the original evidence IDs.

### `backfill_expanded_patent_metadata.py`
Adds inventor, assignee, application number, filing date, and family metadata to the expanded patent dataset.

### `build_patent_inventors.py`
Creates patent-to-inventor links.

### `extract_new_patent_paper_citations.py`
Extracts non-patent literature citations from Google Patents for newly added patents.

### `process_new_patent_citations.py`
Matches extracted literature citations against the existing team paper dataset and creates external literature nodes for unmatched citations.

### `match_patents_to_papers.py`
Matches patent citations from the earlier patent dataset against the team paper dataset.

### `build_external_paper_nodes.py`
Creates standalone literature nodes for cited papers that are not already in the team dataset.

### `find_papers_citing_patents.py`
Searches team paper full text for direct mentions of patent numbers.

### `combine_patent_paper_edges.py`
Combines the earlier and expanded patent-to-paper results into the two master edge files.

### `fetch_patent_abstracts.py`
Retrieves patent abstracts from Google Patents.

### `link_patents_to_entities.py`
Matches KG virus/protein keywords against patent titles and abstracts to generate candidate patent-to-entity links.

### `review_patent_entity_links.py`
Flags potentially ambiguous patent-to-entity links for review.

## Notes

- Patent-to-entity relationships are currently labeled as candidate `related` links based on keyword evidence.
- External patent citations are best described as **external literature** because non-patent citation sections can include sources other than journal papers.
- Patent abstracts were successfully retrieved for all 172 patents.
- The scripts in this folder were used to generate the processed outputs included here.
